# ONG Esperança Viva — Single Page Application (SPA)

Aplicação Web desenvolvida como projeto prático para a ONG Esperança Viva, focada em inclusão digital e captação de voluntários/alunos.

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização responsiva e padronizada.
- **JavaScript (Vanilla - ES6+):** Roteamento dinâmico via `hashchange`, validação nativa de formulários e persistência de dados.

## 📌 Funcionalidades Principais
- Roteamento dinâmico sem recarregamento de página (SPA) com `window.location.hash`.
- Persistência de dados de formulário com `localStorage` (`JSON.stringify` / `JSON.parse`).
- Destaque automático do menu ativo (`updateActiveMenu`).
- Acessibilidade alinhada às diretrizes WCAG 2.1 (Nível AA).

## 🛠️ Estratégia de Versionamento (GitFlow)
- `main`: Versão estável em produção.
- `develop`: Ambiente de desenvolvimento contínuo.
- `feature/*`: Recursos e componentes em construção.
- `hotfix/*`: Correções imediatas.
